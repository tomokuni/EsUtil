# EsUtil.Ui.WinUI3.Annotation 手動確認書

**自動テストで確認できない操作**（実描画・DPI・入力の感触・IME・ウィンドウの配置）の確認項目です。 操作 → 期待結果 → 自動化の可否 の形で書き、**経緯は書きません**（規則は [`.github/ドキュメント規約.md`](../../../.github/ドキュメント規約.md) §12）。

API は `AnnotationEditorPanel` の `Layer`（`AnnotationLayerControl`）と `AnnotationEditorPanel` を操作します。 内部 API（変換中の文字列・キーの処理）はテストからのみ呼べます。

## 1. 本文の表示（編集していないとき）

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 1 | API: `layer.AddBubble(new EsRect(24, 24, 240, 160), "文字")` / GUI: 吹き出しを追加する | 本文が書式（色・太字・斜体・下線・取り消し線）どおりに描かれる | 可（描画結果を比較する） |
| 2 | GUI: 表示倍率を変える | 文字の位置と大きさが画像と一緒に拡大・縮小し、保存画像と同じ比率になる | 一部可（倍率の計算は自動、見た目は目視） |
| 3 | API: `layer.SelectedId = id` / GUI: 吹き出しを選ぶ | 本文の文字が動かない（選ぶ前と同じ位置に描かれる） | 可 |
| 4 | API: `layer.ApplyTextStyle(style with { IsItalic = true })` / GUI: 斜体を設定する | 行の高さが斜体でない行と変わらない | 可（行の実寸を比較する） |

## 2. 本文の編集

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 5 | API: `layer.BeginTextEditing()` / GUI: 本文をクリックする、または Enter を押す | キャレットが表示され、点滅する（選択が無いため書式バーは出ない） | 一部可（点滅の周期は目視） |
| 6 | GUI: 文字を入力する | 入力した文字がその場に表示され、キャレットが進む | 不可（キー入力の宛先が環境依存） |
| 7 | GUI: 日本語入力（IME）で変換する | 変換中の文字列がキャレットの位置に下線付きで表示され、確定すると本文へ入る | 一部可（変換中の文字列の描画は内部 API で再現できる） |
| 8 | GUI: 入力済みの文字列の途中で日本語入力し、変換する | 変換中の文字列がキャレットの位置に表示され、キャレットより後ろの既存の文字と重ならない | 一部可 |
| 9 | GUI: 日本語入力で変換候補を出す | 変換候補のウィンドウが変換中の文字の末尾の近くに出る（画面の隅に出ない） | 不可（OS が描く） |
| 10 | GUI: 矢印キーでキャレットを動かす | キャレットが 1 文字ずつ進み、行をまたげる | 不可 |
| 11 | GUI: Shift + 矢印キー | 選択範囲が広がり、薄い青で表示される | 不可 |
| 12 | GUI: 選択がある状態で矢印キー | 選択が畳まれ、キャレットが選択の端へ移る | 不可 |
| 13 | GUI: Backspace / Delete | 1 文字（絵文字は 1 文字として）削除される | 不可 |
| 14 | GUI: Enter | 改行が入り、行が増える | 不可 |
| 15 | GUI: Escape / Ctrl + Enter | 編集が終わり、キャレットが消える | 不可 |
| 16 | GUI: 絵文字（😀 など）を入力し、Backspace で削除する | 絵文字が 1 文字として削除される（半分に割れない） | 一部可 |

## 6. 図形の追加と選択

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 30 | API: `layer.AddFrame(new EsRect(60, 60, 340, 220))` / GUI: 追加メニューから枠線を選ぶ | 枠線が追加され、その枠線が選択される | 可 |
| 31 | API: `layer.AddBubble(new EsRect(520, 340, 380, 170), "文字")` / GUI: 追加メニューから吹き出しを選ぶ | 吹き出しと本文が表示され、本文の上で編集を始められる | 可 |
| 32 | API: `layer.AddFrameAt(point)` / GUI: 何もない場所を右クリックして追加する | 押した位置を左上とする既定の大きさで追加される | 一部可 |
| 33 | GUI: 注釈の本体を押す | 選択され、選択枠と 8 方向のハンドルが出る | 不可 |
| 34 | GUI: 注釈の無い場所を押してドラッグする | 選択が解除され、操作がプレビュー（パン）へ渡る（`PreviewGestureRequested`） | 不可 |
| 35 | GUI: 注釈の無い場所を右クリックする | 注釈の追加メニューが出る（`AddMenuRequested`） | 不可 |
| 36 | GUI: 注釈を右クリックする | 外観と本文の書式の編集が出る（未選択なら先に選択される） | 不可 |
| 37 | API: `layer.SelectedId = null` / GUI: 選択を解除する | 選択枠とハンドルが消え、`SelectionChanged` が出る | 可 |

## 7. 図形の移動とサイズ変更

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 38 | GUI: 本体をドラッグする | 注釈が移動し、押下から離すまでが 1 手として履歴に入る | 不可 |
| 39 | GUI: 8 方向のハンドルをドラッグする | その方向へサイズが変わり、カーソルの形が方向と一致する | 不可 |

| 42 | GUI: 注釈を画像の外へ移動・サイズ変更する | 画像の内側で止まる | 一部可 |
| 43 | GUI: ドラッグ中に矢印キーを押す | 1 画素ずつ動く（nudge）。 キーを離しても選択は保たれる | 不可 |
| 44 | GUI: 選択中に Enter を押す、またはダブルクリックする | 本文の編集が始まる | 不可 |
| 45 | GUI: 選択中に Delete を押す | 選択中の注釈が消え、元に戻すで戻せる | 一部可 |
