## 1. 概要

`EsUtil.Ui.WinUI3/ColorSelector/sample/` にある **ColorSelectorControl 動作確認用の独立したサンプルアプリケーション**です。

- 設定画面と同じ形（ラベルとコントロールを並べる）で 4 つの色を編集できます（枠線・背景・テキスト・強調）。
- 選択した色の**保存値（`#AARRGGBB`）**が画面の下に表示されます。
- 2 つの色（枠線と背景）はプレビューの枠と背景へ即時反映されます。
- 一覧は標準のコンボボックスの展開ボタンで開き、上部のタブで **カスタム / テーマカラー / 色名 / ColorPicker** を切り替えられます（テーマの色は数が多いため分けています）。 一覧の並び順（色相順 / 色名順）と入力欄の表記（色名 + 不透明度 / `#AARRGGBB`）も切り替えられます。
- 一覧のタブは設定で隠せます（「「カスタム」タブを出す」「テーマカラーのタブを出す」「色名のタブを出す」「ColorPicker のタブを出す」「タブの題名を出す」）。 「「代表色」タブを追加（格子）」を ON にすると、よく使う 16 色が **6 列（`Columns = 6`）の格子**のタブとして増えます。

## 2. 実行方法

```powershell
dotnet run --project EsUtil.Ui.WinUI3/ColorSelector/sample/EsUtil.Ui.WinUI3.ColorSelector.Sample.csproj
```

## 3. 操作方法

| 操作 | 内容 |
| --- | --- |
| 「表示テーマ」を切り替える | サンプル共通の設定行（`SampleTheme`）。 コントロールはフレームワークのテーマから明暗を読むため、指定は不要 |
| テキスト欄へ入力 | 色名（`Red`）/ 16 進（`#RRGGBB`・`#AARRGGBB`）/ 不透明度（`Red+50%`）を受け付ける |
| コンボボックスの展開ボタン | タブ付きの色の一覧を開く（クリックで選択し、保存値へ反映） |
| ColorPicker タブ | カラーピッカーを開く（OK で反映、キャンセルで破棄） |
| 一覧の並び順 | 「色相順」「色名順」を切り替える（すべての行へ反映。 タブ「色名」の並びが変わる） |
| 入力欄の表記 | 「色名 + 不透明度」「#AARRGGBB」を切り替える（すべての行へ反映） |
| 一覧のタブ | 「「カスタム」タブを出す」「テーマカラーのタブを出す」「色名のタブを出す」「ColorPicker のタブを出す」「タブの題名を出す」「「代表色パレット」「代表色」タブを追加」を切り替える（すべての行へ反映） |
| ツールチップ | 入力欄に「色名 + 不透明度」と「#AARRGGBB」が 2 行で出る |
| フォーカスを外す | 無効な入力を最後の有効値へ戻す |

## 4. 検証項目（動作確認チェックリスト）

- [ ] 起動時に 4 行の色が表示され、保存値が画面の下に出る
- [ ] `Red` と入力すると保存値が `#FFFF0000` になる
- [ ] `Red+50%` と入力すると保存値が `#80FF0000` になる
- [ ] `NotAColor` と入力するとエラー表示が出て、フォーカスを外すと元の値へ戻る
- [ ] 展開ボタンで一覧が開き、色を選ぶと保存値とプレビューが変わる
- [ ] ColorPicker タブでカラーピッカーが開き、OK で反映・キャンセルで破棄される
- [ ] 「色名順」へ切り替えると、すべての行の一覧がアルファベット順になる
- [ ] 「#AARRGGBB」へ切り替えると、すべての行の入力欄が `#AARRGGBB` の表記になる
- [ ] 「「代表色パレット」「代表色」タブを追加」を ON にするとタブの行が「代表色パレット / 代表色 / テーマカラー / 色名 / ColorPicker」の 5 つになり、「代表色パレット」は 16 色が 8 列の格子、「代表色」は色名付きの一覧で並ぶ
- [ ] 「「カスタム」タブを出す」「テーマカラーのタブを出す」「色名のタブを出す」「ColorPicker のタブを出す」を OFF にすると、そのタブが一覧から消える
- [ ] タブが 1 つだけのとき「タブの題名を出す」を OFF にすると、一覧の題名の行が消える（2 つ以上なら消えない）
- [ ] 内容の長い一覧を開いても、コントロール（入力欄）の幅が変わらない
- [ ] 一覧をスクロールしたとき、スクロール バーがフライアウトの**右端**に出る（タブの行の方が広いときも同じ）
- [ ] 「「代表色パレット」「代表色」タブを追加」を ON にしてタブを 5 つにしても、**最後のタブが切れず、横スクロール バーが出ない**（タブの幅が均等に詰まり、長い文言は末尾が省略記号で切れる）
- [ ] 1 番目の色を変えるとプレビューの枠、2 番目を変えるとプレビューの背景が変わる
- [ ] 無効な色を入力してフォーカスを外すと最終有効値へ復帰し、枠線が赤くなる（「入力が無効なら枠線を赤くする」が ON のとき）
- [ ] 「文字サイズ」の変更が入力欄の見た目に反映される

## 6. 使い方（初めての方向け）

1. **起動**: 4 行の色選択とプレビューが表示されます。
2. **入力**: 入力欄へ色名や 16 進を入力すると、その場で保存値が更新されます。
3. **一覧**: コンボボックスの展開ボタンを押すとタブ付きの一覧が開きます。 上部のタブで「カスタム」「テーマカラー」「色名」「ColorPicker」を切り替えます。 並び順は画面の「一覧の並び順」で、入力欄の表記は「入力欄の表記」で切り替えます。
4. **ピッカー**: 「ColorPicker」タブを開くとカラーピッカーが表示されます（アルファも編集できます。 OK で反映、キャンセルで破棄）。
5. **保存値**: 設定へ保存する値は `SelectedColor`（`#AARRGGBB`）です。 色名で入力しても正規化されます。
