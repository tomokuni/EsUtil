# EsUtil.Ui.WinUI3.StyledText 手動確認書

**自動テストで確認できない操作**（実描画・DPI・入力の感触・IME・ウィンドウの配置）の確認項目です。 操作 → 期待結果 → 自動化の可否 の形で書き、**経緯は書きません**（規則は [`.github/ドキュメント規約.md`](../../../.github/ドキュメント規約.md) §12）。

API は `StyledTextControl` を操作します。 本文は元画像ピクセルの座標で保持し、表示倍率で DIP へ写します。

## 1. 表示とキャレット

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 1 | GUI: 本文をクリックする | キャレットが押した位置に出て、530 ms 間隔で点滅する | 一部可（点滅は目視） |
| 2 | GUI: 文字を入力する | 入力した文字がキャレットの位置へ入り、キャレットが進む | 不可 |
| 3 | GUI: 選択する | 選択範囲が `TextEditorAppearance.SelectionColor` で表示され、文字が読める | 不可 |
| 4 | GUI: 表示倍率 150%・200% にする | 文字が滲まず、キャレットの太さが DIP で一定 | 不可（DPI は環境依存） |
| 5 | GUI: 日本語・絵文字・記号を混在させる | フォントが代替されても行の高さとベースラインが崩れない | 不可 |

## 2. 編集と IME

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 6 | GUI: 日本語入力（IME）で変換する | 変換中の文字列がキャレットの位置に下線付きで表示され、確定すると本文へ入る | 不可 |
| 7 | GUI: 既存の文字の途中で日本語入力する | 変換中の文字列が後ろの既存の文字と重ならない | 一部可 |
| 8 | GUI: 変換候補を出す | 候補のウィンドウが変換中の文字の末尾の近くに出る（画面の隅に出ない） | 不可（OS が描く） |
| 9 | GUI: 絵文字を入力して Backspace を押す | 絵文字が 1 文字として削除される（半分に割れない） | 一部可 |
| 10 | GUI: 矢印キー・Shift + 矢印キーで移動する | キャレットが 1 クラスタずつ動き、行をまたげる。 Shift で選択が広がる | 不可 |
| 11 | GUI: Ctrl + B / Ctrl + I / Ctrl + U / Alt + Shift + 5 | 太字・斜体・下線・取り消し線が切り替わる（選択が無ければ以降の入力へ効く） | 不可 |
| 12 | GUI: Escape を押す | 編集が終わり、キャレットと書式バーが消える | 不可 |

## 3. 書式バー

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 13 | GUI: 1 文字以上を選ぶ | 書式バーが出る。 選択を畳むと閉じる | 不可 |
| 14 | API: `FormatBarItems` を変える / GUI: 出す項目を減らす | 出さない項目が詰めて並び、空の枠が残らない。 すべて出さないとバーが出ない | 一部可 |
| 15 | GUI: `FormatBarHosting = Popup` で選択する | バーが選択に被らず、置ける領域の外へ出ない。 入りきらないときは下へ回る | 一部可 |
| 16 | GUI: 書式バーをボタンの上からドラッグする | バーが動く。 動かした場合は項目のクリックと見なさない | 不可 |
| 17 | GUI: 書式バーを表示したままウィンドウを移動する | バーが新しい位置へ追随する（前の位置に残らない） | 不可 |
| 18 | GUI: 書式バーの入力欄でキーを打つ | 本文へ転送されない。 フォーカスを戻すと本文のキー操作が再開する | 不可 |
| 19 | GUI: 書式バーで色の一覧を開く | 一覧が潰れずに操作できる | 不可 |

## 4. クリップボードと入力の制御

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 20 | GUI: 文字を選んで Ctrl + C / Ctrl + X / Ctrl + V | クリップボード経由で文字が出入りし、改行が LF に揃う | 不可（クリップボードは環境依存） |
| 21 | API: `IsInputEnabled = false` | フォーカスもキャレットも持たず、ホストの入力で表示だけが変わる | 一部可 |
| 22 | API: `Log` を設定して編集する | `[DBG]` に操作内容と値（文字数・キャレット）が出て、本文が 100 文字で切られる | 可（ログを目視） |
