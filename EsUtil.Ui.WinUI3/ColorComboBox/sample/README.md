## 1. 概要

`EsUtil.Ui.WinUI3/ColorComboBox/sample/` にある **ColorComboBoxControl 動作確認用の独立したサンプルアプリケーション**です。

- 設定画面と同じ形（ラベルとコントロールを並べる）で 4 つの色を編集できます（枠線・背景・テキスト・強調）。
- 選択した色の**保存値（`#AARRGGBB`）**が画面の下に表示されます。
- 2 つの色（枠線と背景）はプレビューの枠と背景へ即時反映されます。
- 一覧の並び順（色相順 / 色名順）と入力欄の表記（色名 + 不透明度 / `#AARRGGBB`）を切り替えられます。

## 2. 実行方法

```powershell
dotnet run --project EsUtil.Ui.WinUI3/ColorComboBox/sample/EsUtil.Ui.WinUI3.ColorComboBox.Sample.csproj
```

### 2.1 バッチファイル（リリースビルド＆起動）

`RunSample.bat` をダブルクリックすると、リリースビルドを行った後、サンプルアプリケーションを起動します。

> 本サンプルは独立したプロジェクトです（`sample/` はコントロール本体のプロジェクト フォルダの外にあり、本体の `csproj` のコンパイル対象には含まれません）。

## 3. 操作方法

| 操作 | 内容 |
| --- | --- |
| テキスト欄へ入力 | 色名（`Red`）/ 16 進（`#RRGGBB`・`#AARRGGBB`）/ 不透明度（`Red+50%`）を受け付ける |
| ▼ ボタン | 色の一覧を開く（クリックで選択し、保存値へ反映） |
| … ボタン | カラーピッカーを開く（OK で反映、キャンセルで破棄） |
| 一覧の並び順 | 「色相順」「色名順」を切り替える（すべての行へ反映） |
| 入力欄の表記 | 「色名 + 不透明度」「#AARRGGBB」を切り替える（すべての行へ反映） |
| スウォッチ / 入力欄へ重ねる | ツールチップに「色名 + 不透明度」と「#AARRGGBB」が 2 行で出る |
| フォーカスを外す | 無効な入力を最後の有効値へ戻す |

## 4. 検証項目（動作確認チェックリスト）

- [ ] 起動時に 4 行の色が表示され、保存値が画面の下に出る
- [ ] `Red` と入力すると保存値が `#FFFF0000` になる
- [ ] `Red+50%` と入力すると保存値が `#80FF0000` になる
- [ ] `NotAColor` と入力するとエラー表示が出て、フォーカスを外すと元の値へ戻る
- [ ] ▼ で一覧が開き、色を選ぶと保存値とプレビューが変わる
- [ ] … でカラーピッカーが開き、OK で反映・キャンセルで破棄される
- [ ] 「色名順」へ切り替えると、すべての行の一覧がアルファベット順になる
- [ ] 「#AARRGGBB」へ切り替えると、すべての行の入力欄が `#AARRGGBB` の表記になる
- [ ] 1 番目の色を変えるとプレビューの枠、2 番目を変えるとプレビューの背景が変わる

## 6. 使い方（初めての方向け）

1. **起動**: 4 行の色選択とプレビューが表示されます。
2. **入力**: テキスト欄へ色名や 16 進を入力すると、その場で保存値が更新されます。
3. **一覧**: ▼ を押すと色の一覧が開きます。 並び順は画面の「一覧の並び順」で、入力欄の表記は「入力欄の表記」で切り替えます。
4. **ピッカー**: … を押すとカラーピッカーが開きます（アルファも編集できます）。
5. **保存値**: 設定へ保存する値は `SelectedColor`（`#AARRGGBB`）です。 色名で入力しても正規化されます。
