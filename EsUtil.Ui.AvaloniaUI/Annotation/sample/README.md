## 1. 概要

市松模様のサンプル画像の上に、枠線 1 件と吹き出し 2 件を置いた状態で起動します。

- **枠線**: 赤い枠・角丸（内側は塗らない）。
- **吹き出し**: 白い内側・黒い枠・しっぽ。 本文の一部だけ太字 + 赤色。
- **吹き出し（見た目の違い）**: 青い枠・水色の塗り・角丸 18・しっぽは右辺。 外観は注釈ごとに保たれる。
- **配置**: サンプル共通の `SampleShell` を使います（左: 設定 / 右上: 画像と操作 / 右下: ログ。 画像とログの境界はドラッグで動かせます）。
- **設定パネル**は「プロパティ設定」「API操作」「サンプル設定」の 3 区分です。

dotnet run -c Release --project EsUtil.Ui.AvaloniaUI/Annotation/sample/EsUtil.Ui.AvaloniaUI.Annotation.Sample.csproj

## 3. 操作方法

| 操作 | 確認できること |
| --- | --- |
| 枠線・吹き出しをクリック | 選択（**8 方向のハンドル**が Marquee の提示層で描かれる） |
| 本体をドラッグ | 移動 |
| ハンドルをドラッグ | サイズ変更 |
| しっぽの先端をドラッグ | 吹き出し口の移動（本体と独立） |
| ダブルクリック / Enter | 本文のその場編集（1 文字以上を選ぶと書式バーが出る） |
| 右クリック | 外観・重なり順の編集 |
| 「枠線を追加」「吹き出しを追加」 | 新しい注釈の追加（既定値を使う） |
| 「本文を編集」 | 本文の編集を開始する |
| 「元に戻す」「やり直す」 / `Ctrl+Z` / `Ctrl+Y` | 変更の取り消しとやり直し（ドラッグ 1 回 = 1 手） |
| 「最前面へ」「最背面へ」 | 選択中の注釈の重なり順（右クリックのパネルと同じ） |
| 「本文を差し替える」 | 選択中の吹き出しの本文をまとめて置き換える（`SetSelectedText`） |
| 「選択を解除」 | 選択を解除する（ハンドルが消える） |
| 「注釈を保存」「注釈を読み込む」 | 注釈ファイル（`%TEMP%\esutil-annotation-sample.annotations.json`）の書き出しと読み込み |
| 「削除」 / `Delete` | 選択中の注釈の削除 |
| 「プロパティ設定」の「行間の倍率」「枠線の太さ」「本文の文字サイズ」 | コントロールの公開プロパティの変更（枠線と文字は**これから追加する注釈**に効く） |
| 「プロパティ設定」の「編集中に書式バーを自動表示」 | 本文で 1 文字以上を選ぶと書式バーが出て、未選択（1 文字未満）なら出ない |
| 「プロパティ設定」の「書式バー: 太字」など 7 項目 | 書式バーからその項目が消え、残りの項目が詰めて並ぶ（バーの幅も縮む。 すべて切るとバー自体が出ない）。 書式バーを出したまま切り替えても落ちない |
| 「プロパティ設定」の「色の表記」「画像を表示」 | 本文の色の表記（色名 + 不透明度 / カラーコード）と、画像の表示の切り替え |
| 「API操作」の「枠線を追加（位置指定）」「吹き出しを追加（位置指定）」 | 位置を指定して注釈を追加する（AddFrameAt / AddBubbleAt） |
| 「API操作」の「選択の書式を太字に」「選択の太字を切替」「本文の 0〜5 を選択」 | 本文の書式の適用・切り替えと、範囲の選択（ApplyTextStyle / TransformTextStyle / SelectText） |
| 「API操作」の「本文の余白を 12 に」「しっぽの幅を 30 に」「外観の枠線を 3 に」 | 選択中の注釈の本文の余白・しっぽ・外観の変更（SetSelectedBodyPadding / UpdateSelectedTail / UpdateSelectedAppearance） |
| 「API操作」の「外観パネルを表示」「外観パネルを閉じる」 | 外観パネルの表示と終了（ShowStyleEditor / CloseStylePanel） |
| 「API操作」の「選択をコピー」「切り取り」「貼り付け」 | 編集中の本文のクリップボード操作（CopyTextSelection / CutTextSelection / PasteText） |
| 「API操作」の「再描画を要求」「合成画像を保存」「当たり判定（位置 200,200）」 | 再描画の要求（InvalidateRender）、合成画像の書き出し（RenderComposedImage）、位置から注釈を引く（HitTestAt） |
| 「プロパティ設定」の「ログ接頭辞」 | ログの接頭辞の変更（`[Annotation]`） |
| 「サンプル設定」の「ログ レベル」 | ログの表示レベルの切り替え（既定 Debug） |

## 4. 検証項目（動作確認チェックリスト）

- [ ] 起動時に枠線 1 件と吹き出し 2 件が表示され、吹き出しごとに外観（枠線・塗り・角丸・しっぽ）が違う
- [ ] クリックで選択され、8 方向のハンドルが出る
- [ ] 本体のドラッグで移動し、ハンドルのドラッグでサイズが変わる
- [ ] しっぽの先端をドラッグすると吹き出し口だけが動く
- [ ] ダブルクリックで本文のその場編集が始まり、文字を入力できる
- [ ] 選択した文字に書式バーで太字・色を適用すると、その範囲だけが変わる
- [ ] 本文で 1 文字以上を選ぶと書式バーが出て、選択を解除すると消える
- [ ] 本文で 1 文字以上を選んで書式バーを出したまま「書式バー: 色」を切ると、色の項目が消えて残りが詰まり（幅も縮み）、7 項目すべてを切ると書式バーが消える
- [ ] 右クリックで外観（枠線・内側・角丸）と重なり順を変えられる
- [ ] 「最前面へ」「最背面へ」で重なり順が変わる
- [ ] 「本文を差し替える」で本文が置き換わり、「元に戻す」で戻せる
- [ ] 「注釈を保存」のあと「注釈を読み込む」で同じ見た目に戻る（件数・選択・しっぽ・外観が一致する）
- [ ] 状態の行に件数・選択・元に戻せる/やり直せる・本文の選択範囲・当たり判定の結果が出る
- [ ] `Ctrl+Z` で元に戻り、`Ctrl+Y` でやり直せる
- [ ] ログに「ファサードを作成しました」「注釈を作成」などが表示される（ログ レベル Debug）

## 6. 使い方（初めての方向け）

1. サンプルを起動します（上の「実行方法」）。
2. 枠線か吹き出しをクリックして選択し、本体をドラッグして移動します。
3. 本文をダブルクリックし、文字を選んで書式バーの B を押します（その範囲だけが太字になります）。
4. プロパティ設定で枠線の太さを変え、「枠線を追加」を押します（新しい枠線に反映されます）。
5. `Ctrl+Z` で変更を戻します。
