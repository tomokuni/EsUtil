## 1. 概要

市松模様のサンプル画像の上に、枠線 1 件と吹き出し 1 件を置いた状態で起動します。

- **枠線**: 赤い枠・角丸（内側は塗らない）。
- **吹き出し**: 白い内側・黒い枠・しっぽ。 本文の一部だけ太字 + 赤色。
- **左の設定ペイン**: 既定値（枠線・吹き出し・本文の書式）と全体設定（行間の倍率・ハンドルの掴む半径・書式バーの代表色の列数）を変えられます。

## 3. 操作方法

| 操作 | 確認できること |
| --- | --- |
| 枠線・吹き出しをクリック | 選択（**8 方向のハンドル**が Marquee の提示層で描かれる） |
| 本体をドラッグ | 移動（Marquee の通知が文書へ書き戻る） |
| ハンドルをドラッグ | サイズ変更 |
| しっぽの先端の円をドラッグ | 吹き出し口の移動（本体と独立） |
| 右クリック | 外観（枠線・内側・角丸）・吹き出し・重なり順の編集 |
| ダブルクリック / Enter | 本文のその場編集（書式バーが出る） |
| 左の設定ペイン | 既定値と全体設定の変更（変更後に追加した注釈へ効く） |
| 「枠線を追加」「吹き出しを追加」 | 新しい注釈の追加（既定値を使う） |
| Delete | 選択中の注釈の削除 |
| 方向キー | nudge（1 px。 `Shift` 併用で 10 px） |
| 「元に戻す」「やり直す」 / `Ctrl+Z` / `Ctrl+Y` | 変更の取り消しとやり直し（ドラッグ 1 回 = 1 手） |

**本文のその場編集**: 本文をダブルクリック（または Enter・「本文を編集」）すると、表示中のレイアウトのままキャレットが立ちます。 文字を入力でき、`←→↑↓`・`Home`・`End` でキャレットを動かし、`Shift` 併用で選択します。 日本語入力（IME）にも対応します。

**文字単位の書式（編集中）**: 文字を選び、本文の上に出る書式バーでフォント・大きさ・色・B / I / U / S を押すと、その範囲だけにその場で反映されます。 ショートカットは `Ctrl+B` / `Ctrl+I` / `Ctrl+U`、取り消し線は `Alt+Shift+5` です。 終えるときは `Ctrl+Enter`・本文の外側をクリック・`Esc` を使います。

**色の選択**: 入力欄は「■ + 色名」で表示します。 書式バーと右クリックのフライアウトは「代表色」と「ColorPicker」のタブを出します。 左の設定ペインの色は「代表色」「テーマカラー」「色名」「ColorPicker」のタブを出します。

## 6. 使い方（初めての方向け）

1. サンプルを起動します（上の「実行方法」）。
2. 枠線か吹き出しをクリックして選択し、本体をドラッグして移動します。
3. 本文をダブルクリックし、文字を選んで書式バーの B を押します（その範囲だけが太字になります）。
4. 左の設定ペインで枠線の色を変え、「枠線を追加」を押します（新しい枠線に反映されます）。
5. `Ctrl+Z` で変更を戻します。
