## 1. 概要

| 項目 | 内容 |
| --- | --- |
| 目的 | 書式付きの本文を、入力欄を重ねずにその場で表示・編集する |
| 対象 UI | Avalonia UI |
| 座標 | 元画像ピクセル（`RenderScale` で DIP へ写す） |
| 文字位置 | 本文の先頭からの文字数（移動・削除は書記素クラスタの境界） |

## 2. 技術スタック

| 項目 | 内容 |
| --- | --- |
| 対象フレームワーク | `net10.0-windows10.0.17763.0` |
| 参照 | `EsUtil.Feature.Text.Core` / `EsUtil.Platform.Core` |
| 描画 | Avalonia の `DrawingContext`（`FormattedText`） |
| テスト | xUnit v3（Avalonia ヘッドレス） |

## 3. アーキテクチャ

- **規則は提示層が単一所有します**: 折り返しと行の配置は `TextLayout`、行と文字位置の対応は `TextLineIndex` / `TextLineLayout`、書記素クラスタは `TextCursor`、編集の状態は `TextEditState`、キーの割り当ては `TextEditKeyMap` です。
- **本コントロールはフレームワーク固有の配線だけを行います**: 描画・入力イベント・IME・クリップボード・フォーカス。
- **本文は `Text` が単一所有します**: 編集の結果は新しい `RichText` として `Text` へ書き戻します。

## 4. コンポーネント

| コンポーネント | 責務 |
| --- | --- |
| `RichTextEditorControl` | 本文の描画・入力の受付・API の公開（部分クラスで編集の配線を分ける） |
| `RichTextPainter`（内部） | 解決済みの行を Avalonia の描画 API へ写す・実寸の計測・フォントの解決 |
| `RichTextEditorInputClient`（内部） | IME とのやり取り（変換候補の位置・選択範囲・変換中の文字列） |

**ログ**: 本アセンブリはログを出力しません（計算と描画の部品であり、記録は利用側が行う）。

## 6. 例外処理ポリシー

| 場面 | 扱い |
| --- | --- |
| 引数が null | `ArgumentNullException`（公開メソッドの入口で 1 回だけ検証する） |
| 文字位置が範囲外 | 例外にしない（本文の範囲・クラスタの境界へ丸める） |
| 大きさが 0 | 何も描かない（レイアウト前の状態は正常） |
| クリップボードが使えない | 何もしない（環境によっては取得できない） |

共通方針は [`.github/例外処理規約.md`](../../../.github/例外処理規約.md) が所有します。
