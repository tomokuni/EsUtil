# EsUtil.Ui.AvaloniaUI.StyledText 手動確認書

**自動テストで確認できない操作**（実描画・DPI・入力の感触・IME・ウィンドウの配置）の確認項目です。 **AI が画面キャプチャで確認できる項目**と**人が実施する項目**に分けて書き、**経緯は書きません**（規則は [`.github/ドキュメント規約.md`](../../../.github/ドキュメント規約.md) §12）。

API は `StyledTextControl` を操作します。 本文は元画像ピクセルの座標で保持し、表示倍率で DIP へ写します。

## 1. AI が実施できる項目（画面キャプチャ）

サンプル（[`sample/README.md`](../sample/README.md)）を起動し、表の順に操作して画面をキャプチャし、期待結果と比べます。 操作は API か、キー・ポインターの自動入力で行います。

### 1.1 表示とキャレット

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 1 | GUI: 本文をクリックする | キャレットが押した位置に出て、530 ms 間隔で点滅する |
| 2 | GUI: 文字を入力する | 入力した文字がキャレットの位置へ入り、キャレットが進む |
| 3 | GUI: 選択する | 選択範囲が `TextEditorAppearance.SelectionColor` で表示され、文字が読める |
| 5 | GUI: 日本語・絵文字・記号を混在させる | フォントが代替されても行の高さとベースラインが崩れない |

### 1.2 編集と IME

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 9 | GUI: 絵文字を入力して Backspace を押す | 絵文字が 1 文字として削除される（半分に割れない） |
| 10 | GUI: 矢印キー・Shift + 矢印キーで移動する | キャレットが 1 クラスタずつ動き、行をまたげる。 Shift で選択が広がる |
| 11 | GUI: Ctrl + B / Ctrl + I / Ctrl + U / Alt + Shift + 5 | 太字・斜体・下線・取り消し線が切り替わる（選択が無ければ以降の入力へ効く） |
| 12 | GUI: Escape を押す | 編集が終わり、キャレットと書式バーが消える |

### 1.3 書式バー

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 13 | GUI: 1 文字以上を選ぶ | 書式バーが出る。 選択を畳むと閉じる |
| 14 | API: `FormatBarItems` を変える / GUI: 出す項目を減らす | 出さない項目が詰めて並び、空の枠が残らない。 すべて出さないとバーが出ない |
| 15 | GUI: `FormatBarHosting = Popup` で選択する | バーが選択に被らず、置ける領域の外へ出ない。 入りきらないときは下へ回る |
| 17 | GUI: 書式バーを表示したままウィンドウを移動する | バーが新しい位置へ追随する（前の位置に残らない） |
| 18 | GUI: 書式バーの入力欄でキーを打つ | 本文へ転送されない。 フォーカスを戻すと本文のキー操作が再開する |
| 19 | GUI: 書式バーで色の一覧を開く | 一覧が潰れずに操作できる |

### 1.4 クリップボードと入力の制御

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 20 | GUI: 文字を選んで Ctrl + C / Ctrl + X / Ctrl + V | クリップボード経由で文字が出入りし、改行が LF に揃う |
| 21 | API: `IsInputEnabled = false` | フォーカスもキャレットも持たず、ホストの入力で表示だけが変わる |
| 22 | API: `Log` を設定して編集する | `[DBG]` に操作内容と値（文字数・キャレット）が出て、本文が 100 文字で切られる |

## 2. 人が実施する項目（AI は実施できない）

画面キャプチャでは判定できない項目です。 人が操作して確かめ、**AI が実施できない理由**を表の最後の列に示します。

### 2.1 表示とキャレット

| # | 操作（API / GUI） | 期待結果 | AI が実施できない理由 |
| --- | --- | --- | --- |
| 4 | GUI: 表示倍率 150%・200% にする | 文字が滲まず、キャレットの太さが DIP で一定 | 文字の滲みは DPI と目視に依存する（キャプチャでは滲みを判定できない） |

### 2.2 編集と IME

| # | 操作（API / GUI） | 期待結果 | AI が実施できない理由 |
| --- | --- | --- | --- |
| 6 | GUI: 日本語入力（IME）で変換する | 変換中の文字列がキャレットの位置に下線付きで表示され、確定すると本文へ入る | IME の変換は環境の入力プロファイルと辞書に依存する |
| 7 | GUI: 既存の文字の途中で日本語入力する | 変換中の文字列が後ろの既存の文字と重ならない | 同上（変換中の文字列は IME が決める） |
| 8 | GUI: 変換候補を出す | 候補のウィンドウが変換中の文字の末尾の近くに出る（画面の隅に出ない） | 変換候補のウィンドウは OS が描き、位置も OS が決める |

### 2.3 書式バー

| # | 操作（API / GUI） | 期待結果 | AI が実施できない理由 |
| --- | --- | --- | --- |
| 16 | GUI: 書式バーをボタンの上からドラッグする | バーが動く。 動かした場合は項目のクリックと見なさない | ポップアップの別ウィンドウへのドラッグはウィンドウのアクティブ化に依存し、自動入力では再現できなかった |
