## 1. 概要

`EsUtil.Ui.AvaloniaUI.StyledText` の使い方を**動くアプリ**として確認するためのサンプルです（AvaloniaUI）。

| 示すこと | 内容 |
| --- | --- |
| その場で表示・編集 | 入力欄を重ねず、本文を書式どおりに描いてその場で編集する |
| API からの操作 | キャレット・選択・入力・削除・書式・クリップボードをすべて API で行う |
| 書式の反映 | run 単位の書式（太字・斜体・下線・取り消し線・色・大きさ）がその場で反映される |
| 表示の調整 | 行間と表示倍率を変えても、文字の位置と比率が崩れない |

## 2. 実行方法

```powershell
dotnet run --project EsUtil.Ui.AvaloniaUI/StyledText/sample/EsUtil.Ui.AvaloniaUI.StyledText.Sample.csproj
```

## 3. 操作方法

| 操作 | 結果 |
| --- | --- |
| 本文をクリックする | キャレットが表示され、点滅する（編集の開始） |
| 文字を入力する | 入力した文字がその場に表示される |
| 日本語入力（IME）で変換する | 変換中の文字列がキャレットの位置に下線付きで表示される |
| 「行間」を動かす | 行の間隔が変わる（文字の大きさは変わらない） |
| 「表示倍率」を動かす | 本文が拡大・縮小する（キャレットの太さは画面上で一定のまま） |
| 「文字サイズ」を動かす | 本文全体の文字の大きさが変わる |
| 「編集を開始」「編集を終了」 | 編集の状態が切り替わる（キャレットの表示も追随する） |
| 「すべて選択」 | 本文がすべて選択される |
| 「太字の切替」など | 選択範囲（選択が無ければ以降の入力）の書式が変わる |
| 「選択をコピー」「選択を切り取り」「貼り付け」 | クリップボードを介して本文をやり取りする |
| 「本文を初期化」 | 本文が最初の 1 行へ戻る |

## 4. 検証項目（動作確認チェックリスト）

| # | 操作 | 期待結果 |
| --- | --- | --- |
| 1 | 起動する | 本文が書式（太字・色）どおりに表示される |
| 2 | 本文をクリックする | キャレットがクリックした位置に置かれる |
| 3 | 文字を入力する | 入力した位置に文字が入り、キャレットが進む |
| 4 | 「すべて選択」を押す | 本文全体が薄い青で選択される |
| 5 | 選択したまま「太字の切替」を押す | 選択範囲だけが太くなる（押すたびに切り替わる） |
| 6 | 選択を解除して「太字の切替」を押し、文字を入力する | 入力する文字だけが太くなる（既存の文字は変わらない） |
| 7 | 「表示倍率」を 2.0 にする | 本文が 2 倍になる（キャレットが細いまま） |
| 8 | 日本語入力で変換する | 変換候補がキャレットの近くに出る（画面の隅に出ない） |
| 9 | 絵文字を入力して Backspace を押す | 絵文字が 1 文字として削除される（半分に割れない） |
| 10 | 「選択をコピー」して「貼り付け」を押す | 選択した文字がキャレットの位置に入る |
| 11 | 本文に「斜体の切替」を適用する | 行の高さが変わらない（行の間隔が広がらない） |
| 12 | 本文の途中にキャレットを置いて日本語入力し、変換する | 変換候補が変換中の文字の近くに出る（画面の隅や離れた行に出ない） |
| 13 | 本文の余白をクリックする | 編集が始まり、キャレットが表示される |

## 6. 使い方（初めての方向け）

```csharp
using EsUtil.Feature.StyledText;
using EsUtil.Feature.StyledText.Core.Defaults;
using EsUtil.Ui.AvaloniaUI.StyledText;

var editor = new StyledTextControl
{
    RichTextValue = RichText.Create("ここが重要です。", TextDefaults.DefaultStyle),
    LineHeightFactor = 1.2,
};

editor.RichTextChanged += (_, _) => Save(editor.RichTextValue);
editor.BeginEditing();
editor.Select(2, 4);
editor.ApplyTextStyle(TextDefaults.DefaultStyle with { IsBold = true });
```
