## 1. AI が実施できる項目（画面キャプチャ）

サンプル（[`sample/README.md`](../sample/README.md)）を起動し、表の順に操作して画面をキャプチャし、期待結果と比べます。 操作は API か、キー・ポインターの自動入力で行います。 日本語入力の変換と候補は半角/全角キーで IME を開いて入力し、候補のウィンドウを含めてキャプチャします。 カーソルの形はキャプチャへカーソルを重ねて（`GetCursorInfo` と `DrawIconEx`）確かめ、表示の有無は `GetCursorInfo` の `flags` で確かめます。

### 1.1 拡大の見た目

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 1 | API: `Options = Options with { ZoomLevel = 8 }` / GUI: 拡大率を変える | 拡大率どおりに 8 倍で表示され、十字線と枠線の位置がずれない |
| 2 | API: `CenterPoint = new EsPoint(100, 80)` / GUI: 拡大中心を移す | 中心の画素が十字線の交点に来る |
| 3 | API: `Appearance = Appearance with { ShowCoordLabel = false }` | 座標ラベルだけが消え、枠線と十字線は残る |
| 5 | GUI: 角丸を変える（`Appearance.CornerRadius`） | 角の丸みが指定どおりになる（0 は直角） |
| 6 | GUI: ウィンドウを移動・リサイズする | ルーペの位置と大きさが崩れず、ラベルが切れない |

### 1.2 外観

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 7 | API: `Appearance.PasteboardColor` を変える / GUI: 画像の外を写す | 画像外が指定色で塗られ、前のフレームの残像が出ない |
| 8 | API: `Appearance.ShowPasteboard = false` | 画像外が透明になり、背後の内容が見える |
| 9 | API: `Appearance.CoordLabelFontSize` を変える | ラベルの文字だけが変わり、十字線と枠線は変わらない |
| 10 | GUI: 十字線の色を半透明にする | 下の画像が透けて見える（塗りつぶしで隠れない） |

### 1.3 拡大元と表示用の射影

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 11 | API: `DisplaySource` に拡大元と同寸法の射影を渡す | 見た目が変わらず、切り出しの複製が作られない |
| 12 | API: `DisplaySource` に拡大元と異なる寸法の射影を渡す | 射影が無視され、拡大元から描かれる（拡大位置がずれない） |
| 13 | API: 破棄済みの `Source` を設定する | 例外で落ちず、画像外の色だけが描かれ、`[ERR]` に 1 行記録される |
| 14 | GUI: 大きな画像を拡大する | 表示が崩れず、スクロールしても拡大位置がずれない |

### 1.4 追従と描画の更新

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 15 | API: `CenterPointProvider` を設定 / GUI: ホストのズーム・パンを動かす | ルーペの内容と座標ラベルが 1 フレーム遅れずに追従する |
| 16 | API: `DrawPlanResolver` でラベルの文言を差し替える | 差し替えた文言と配置が、表示の測定と描画の両方へ同じように効く（枠だけずれない） |
| 17 | API: `InvalidateRender()` / GUI: ホストのスクロールに合わせる | 変更後の位置と倍率が次の描画で反映され、前の内容が残らない |
| 18 | GUI: `Appearance` を表示中に変える | 次の描画から新しい外観になり、前の外観が残らない |

## 2. 人が実施する項目（AI は実施できない）
