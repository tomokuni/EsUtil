## 1. AI が実施できる項目（画面キャプチャ）

サンプル（[`sample/README.md`](../sample/README.md)）を起動し、表の順に操作して画面をキャプチャし、期待結果と比べます。 操作は API か、キー・ポインターの自動入力で行います。

### 1.1 スクロールと配置

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 2 | GUI: ウィンドウの幅を変える | 列数と項目の位置が追随し、`SlotBounds` と実際の位置が一致する |
| 3 | API: `ScrollToIndex(i)` | 指定した項目が表示領域へ入る |
| 4 | GUI: 高さが足りない状態にする | 項目が重ならず、隠れた項目はスクロールで見られる |

### 1.2 選択と操作

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 6 | GUI: 項目を 1 回押す | 選択の表示が移り、`SelectionChanged` が 1 回だけ出る |
| 7 | GUI: 項目を 2 回押す | `ItemActivated` が `Tag` 付きで出る |
| 8 | API: `SelectedIndex = -1` / 範囲外の値 | 選択が解除され、例外が出ない |
| 9 | GUI: 項目の無い領域を押す | 選択が解除される（項目の選択が残らない） |
| 10 | API: `Add(image, caption, toolTip, tag)` | 追加した項目が末尾に出て、返り値の添字と一致する |

### 1.3 表示と外観

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 11 | GUI: 長い名前を付ける | 名前が省略記号で切れ、ツールチップで全体が読める |
| 12 | API: `SetImage(i, null)` / GUI: 画像を消す | 枠だけが残り、例外が出ない |
| 13 | GUI: 明暗テーマを切り替える | ホバーと選択の背景色が切り替わる（切替の直後に反映される） |
| 14 | API: `Options` / `Appearance` を変える | 間隔・大きさ・影が次の描画で反映され、位置が崩れない |
| 15 | GUI: 項目が 0 件の状態にする | 空の領域が描かれ、例外が出ない |
| 16 | API: `Refresh()` | 外部で変えた外観の値が配置と描画へ反映される |

## 2. 人が実施する項目（AI は実施できない）

画面キャプチャでは判定できない項目です。 人が操作して確かめ、**AI が実施できない理由**を表の最後の列に示します。

### 2.1 スクロールと配置

| # | 操作（API / GUI） | 期待結果 | AI が実施できない理由 |
| --- | --- | --- | --- |
| 1 | GUI: ホイールを回す、またはスクロール バーを動かす | 一覧が滑らかにスクロールし、項目が欠けない | スクロールの滑らかさは時間と目視に依存する |
| 5 | GUI: 表示倍率 150%・200% にする | 画像が粗くならず、余白が DIP で一定 | 画像の粗さと余白は DPI と目視に依存する |
