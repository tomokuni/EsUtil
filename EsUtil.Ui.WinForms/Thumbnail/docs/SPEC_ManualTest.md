# EsUtil.Ui.WinForms.Thumbnail 手動確認書

**自動テストで確認できない操作**（実描画・DPI・入力の感触・IME・ウィンドウの配置）の確認項目です。 操作 → 期待結果 → 自動化の可否 の形で書き、**経緯は書きません**（規則は [`.github/ドキュメント規約.md`](../../../.github/ドキュメント規約.md) §12）。

API は `ThumbnailControl` を操作します。 スクロールとホイールは各 UI の仕組み（スクロール ビュー）が担います。

## 1. スクロールと配置

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 1 | GUI: ホイールを回す、またはスクロール バーを動かす | 一覧が滑らかにスクロールし、項目が欠けない | 不可 |
| 2 | GUI: ウィンドウの幅を変える | 列数と項目の位置が追随し、`SlotBounds` と実際の位置が一致する | 一部可 |
| 3 | API: `ScrollToIndex(i)` | 指定した項目が表示領域へ入る | 一部可 |
| 4 | GUI: 高さが足りない状態にする | 項目が重ならず、隠れた項目はスクロールで見られる | 不可 |
| 5 | GUI: 表示倍率 150%・200% にする | 画像が粗くならず、余白が DIP で一定 | 不可（DPI は環境依存） |

## 2. 選択と操作

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 6 | GUI: 項目を 1 回押す | 選択の表示が移り、`SelectionChanged` が 1 回だけ出る | 一部可 |
| 7 | GUI: 項目を 2 回押す | `ItemActivated` が `Tag` 付きで出る | 一部可 |
| 8 | API: `SelectedIndex = -1` / 範囲外の値 | 選択が解除され、例外が出ない | 可 |
| 9 | GUI: 項目の無い領域を押す | 選択が解除される（項目の選択が残らない） | 不可 |
| 10 | API: `Add(image, caption, toolTip, tag)` | 追加した項目が末尾に出て、返り値の添字と一致する | 可 |

## 3. 表示と外観

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 11 | GUI: 長い名前を付ける | 名前が省略記号で切れ、ツールチップで全体が読める | 不可 |
| 12 | API: `SetImage(i, null)` / GUI: 画像を消す | 枠だけが残り、例外が出ない | 可 |
| 13 | GUI: 明暗テーマを切り替える | ホバーと選択の背景色が切り替わる（切替の直後に反映される） | 不可 |
| 14 | API: `Options` / `Appearance` を変える | 間隔・大きさ・影が次の描画で反映され、位置が崩れない | 一部可 |
| 15 | GUI: 項目が 0 件の状態にする | 空の領域が描かれ、例外が出ない | 可 |
| 16 | API: `Refresh()` | 外部で変えた外観の値が配置と描画へ反映される | 一部可 |
