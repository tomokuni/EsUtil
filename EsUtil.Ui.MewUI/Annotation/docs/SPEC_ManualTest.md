# EsUtil.Ui.MewUI.Annotation 手動確認書

**自動テストで確認できない操作**（実描画・DPI・入力の感触・IME・ウィンドウの配置）の確認項目です。 操作 → 期待結果 → 自動化の可否 の形で書き、**経緯は書きません**（規則は [`.github/ドキュメント規約.md`](../../../.github/ドキュメント規約.md) §12）。

API は `AnnotationEditorPanel` の `Layer`（`AnnotationLayerControl`）を操作します。 内部 API（変換中の文字列・キーの処理）はテストからのみ呼べます。

## 1. 本文の表示（編集していないとき）

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 1 | API: `layer.AddBubble(new EsRect(24, 24, 240, 160), "文字")` / GUI: 吹き出しを追加する | 本文が書式（色・太字・斜体・下線・取り消し線）どおりに描かれる | 可（描画結果を比較する） |
| 2 | GUI: 表示倍率を変える | 文字の位置と大きさが画像と一緒に拡大・縮小し、保存画像と同じ比率になる | 一部可（倍率の計算は自動、見た目は目視） |
| 3 | API: `layer.SelectedId = id` / GUI: 吹き出しを選ぶ | 本文の文字が動かない（選ぶ前と同じ位置に描かれる） | 可 |
| 4 | API: `layer.ApplyTextStyle(style with { IsItalic = true })` / GUI: 斜体を設定する | 行の高さが斜体でない行と変わらない | 可（行の実寸を比較する） |

## 2. 本文の編集

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 5 | API: `layer.BeginTextEditing()` / GUI: 本文をクリックする、または Enter を押す | キャレットが表示され、点滅する | 一部可（点滅の周期は目視） |
| 6 | GUI: 文字を入力する | 入力した文字がその場に表示され、キャレットが進む | 不可（キー入力の宛先が環境依存） |
| 7 | GUI: 日本語入力（IME）で変換する | 変換中の文字列がキャレットの位置に下線付きで表示され、確定すると本文へ入る | 一部可（変換中の文字列の描画は内部 API で再現できる） |
| 8 | GUI: 入力済みの文字列の途中で日本語入力し、変換する | 変換中の文字列がキャレットの位置に表示され、キャレットより後ろの既存の文字と重ならない | 一部可 |
| 9 | GUI: 日本語入力で変換候補を出す | 変換候補のウィンドウが変換中の文字の末尾の近くに出る（画面の隅に出ない） | 不可（OS が描く） |
| 10 | GUI: 矢印キーでキャレットを動かす | キャレットが 1 文字ずつ進み、行をまたげる | 不可 |
| 11 | GUI: Shift + 矢印キー | 選択範囲が広がり、薄い青で表示される | 不可 |
| 12 | GUI: 選択がある状態で矢印キー | 選択が畳まれ、キャレットが選択の端へ移る | 不可 |
| 13 | GUI: Backspace / Delete | 1 文字（絵文字は 1 文字として）削除される | 不可 |
| 14 | GUI: Enter | 改行が入り、行が増える | 不可 |
| 15 | GUI: Escape / Ctrl + Enter | 編集が終わり、キャレットが消える | 不可 |
| 16 | GUI: 絵文字（😀 など）を入力し、Backspace で削除する | 絵文字が 1 文字として削除される（半分に割れない） | 一部可 |

## 3. 書式の操作

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 17 | API: `layer.ApplyTextStyle(start, length, style)` / GUI: 文字を選び、書式バーの太字を押す | 選択した文字だけが太くなる | 可 |
| 18 | GUI: 選択が無い状態で書式バーの太字を押し、文字を入力する | 入力する文字だけが太くなる（既存の文字は変わらない） | 不可 |
| 19 | GUI: Ctrl + B / Ctrl + I / Ctrl + U | 太字・斜体・下線が切り替わる | 不可 |
| 20 | GUI: Alt + Shift + 5 | 取り消し線が切り替わる | 不可 |
| 21 | GUI: 書式バーを押す | フォーカスが本文から外れず、選択範囲が保たれる | 不可 |
| 22 | GUI: 書式バーを表示したまま、アプリのウィンドウを移動する | 書式バーが閉じる（移動前の位置に残らない） | 不可 |
| 23 | API: `panel.GetPanelSize(AnnotationPanelKind.FormatBar)` / GUI: 書式バーを表示する | 右端の項目まで切れずに表示される（表示できる幅が中身の希望寸法以上になる） | 可 |

## 4. クリップボード

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 24 | GUI: 文字を選んで Ctrl + C（API は提供しない） | 選択した文字が貼り付く | 不可（クリップボードは環境依存） |
| 25 | GUI: 文字を選んで Ctrl + X（API は提供しない） | 選択した文字が消え、他へ貼り付くと戻る | 不可 |
| 26 | GUI: Ctrl + V（API は提供しない） | クリップボードの文字がキャレットの位置へ入る（改行は LF に揃う） | 不可 |

## 5. 編集の終了と文書への反映

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 27 | API: `layer.EndTextEditing()` / GUI: 注釈の外をクリックする | 編集が終わり、変更が文書へ入る（元に戻すで戻せる） | 一部可 |
| 28 | API: `layer.Core.SaveDocument` と読み込み / GUI: 保存して開き直す | 編集した内容と書式が残る | 可 |
| 29 | API: `layer.SelectedId = otherId` / GUI: 編集中に別の吹き出しを選ぶ | 前の本文の変更が確定し、新しい吹き出しの本文が表示される | 可 |
