# EsUtil.Ui.MewUI.Loupe 手動確認書

**自動テストで確認できない操作**（実描画・DPI・入力の感触・IME・ウィンドウの配置）の確認項目です。 操作 → 期待結果 → 自動化の可否 の形で書き、**経緯は書きません**（規則は [`.github/ドキュメント規約.md`](../../../.github/ドキュメント規約.md) §12）。

API は `LoupeControl` を操作します。 拡大元はコアの画像（`EsReadOnlyBitmap`）で渡します。

## 1. 拡大の見た目

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 1 | API: `Options = Options with { ZoomLevel = 8 }` / GUI: 拡大率を変える | 拡大率どおりに 8 倍で表示され、十字線と枠線の位置がずれない | 一部可（倍率の計算は自動、見た目は目視） |
| 2 | API: `CenterPoint = new EsPoint(100, 80)` / GUI: 拡大中心を移す | 中心の画素が十字線の交点に来る | 一部可 |
| 3 | API: `Appearance = Appearance with { ShowCoordLabel = false }` | 座標ラベルだけが消え、枠線と十字線は残る | 可 |
| 4 | GUI: 表示倍率 150%・200% で表示する | 枠線の太さが DIP で一定（画面が大きくなっても太くならない） | 不可（DPI は環境依存） |
| 5 | GUI: 角丸を変える（`Appearance.CornerRadius`） | 角の丸みが指定どおりになる（0 は直角） | 一部可 |
| 6 | GUI: ウィンドウを移動・リサイズする | ルーペの位置と大きさが崩れず、ラベルが切れない | 不可 |

## 2. 外観

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 7 | API: `Appearance.PasteboardColor` を変える / GUI: 画像の外を写す | 画像外が指定色で塗られ、前のフレームの残像が出ない | 一部可 |
| 8 | API: `Appearance.ShowPasteboard = false` | 画像外が透明になり、背後の内容が見える | 一部可 |
| 9 | API: `Appearance.CoordLabelFontSize` を変える | ラベルの文字だけが変わり、十字線と枠線は変わらない | 一部可 |
| 10 | GUI: 十字線の色を半透明にする | 下の画像が透けて見える（塗りつぶしで隠れない） | 不可 |

## 3. 拡大元と表示用の射影

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 11 | API: `DisplaySource` に拡大元と同寸法の射影を渡す | 見た目が変わらず、切り出しの複製が作られない | 一部可 |
| 12 | API: `DisplaySource` に拡大元と異なる寸法の射影を渡す | 射影が無視され、拡大元から描かれる（拡大位置がずれない） | 一部可 |
| 13 | API: 破棄済みの `Source` を設定する | 例外で落ちず、画像外の色だけが描かれ、`[ERR]` に 1 行記録される | 可（ログを確認） |
| 14 | GUI: 大きな画像を拡大する | 表示が崩れず、スクロールしても拡大位置がずれない | 不可 |

## 4. 追従と描画の更新

| # | 操作（API / GUI） | 期待結果 | 自動化 |
| --- | --- | --- | --- |
| 15 | API: `CenterPointProvider` を設定 / GUI: ホストのズーム・パンを動かす | ルーペの内容と座標ラベルが 1 フレーム遅れずに追従する | 一部可 |
| 16 | API: `DrawPlanResolver` でラベルの文言を差し替える | 差し替えた文言と配置が、表示の測定と描画の両方へ同じように効く（枠だけずれない） | 可 |
| 17 | API: `InvalidateRender()` / GUI: ホストのスクロールに合わせる | 変更後の位置と倍率が次の描画で反映され、前の内容が残らない | 一部可 |
| 18 | GUI: `Appearance` を表示中に変える | 次の描画から新しい外観になり、前の外観が残らない | 不可 |
