## 1. AI が実施できる項目（画面キャプチャ）

サンプル（[`sample/README.md`](../sample/README.md)）を起動し、表の順に操作して画面をキャプチャし、期待結果と比べます。 操作は API か、キー・ポインターの自動入力で行います。 日本語入力の変換と候補は半角/全角キーで IME を開いて入力し、候補のウィンドウを含めてキャプチャします。 カーソルの形はキャプチャへカーソルを重ねて（`GetCursorInfo` と `DrawIconEx`）確かめ、表示の有無は `GetCursorInfo` の `flags` で確かめます。

### 1.1 一覧の表示

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 1 | GUI: 展開ボタン、Alt + ↓、F4 を押す | タブ付きの一覧が出て、前回開いたタブから始まる |
| 2 | GUI: タブを切り替える | カスタム → テーマカラー → 色名 → ColorPicker の順に並ぶ |
| 3 | GUI: 一覧を開く | コントロールの幅が変わらず、一覧が横スクロールしない（スクロール バーは右端） |
| 4 | GUI: 明暗・アクセントを切り替える | テーマカラーの項目が切り替わり、選択中のテーマ色も追随する |

### 1.2 入力とバリデーション

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 6 | API: `SelectedColor = "Red+50%"` / GUI: 入力する | 表示が `Red+50%`、保存値が `#80FF0000` になる |
| 7 | GUI: 無効な文字列を入力してフォーカスを外す | 最後の有効値へ戻る |
| 8 | GUI: `HighlightBorderOnError = true` で無効な文字列を入力する | 入力中に枠線が赤くなる |
| 9 | API: `TextFormat = HexCode` | 入力欄が `#AARRGGBB` 表記になる。 テーマ色の選択中は `テーマ: 〜` になる |
| 10 | GUI: 入力欄で日本語入力（IME）を使う | 変換中の文字列が入力欄に出て、確定すると入力値になる |

### 1.3 カラーピッカーとカスタム タブ

| # | 操作（API / GUI） | 期待結果 |
| --- | --- | --- |
| 11 | GUI: ColorPicker タブで OK を押す | 色と不透明度が保存値（`#AARRGGBB`）へ入る |
| 12 | GUI: ColorPicker タブでキャンセルを押す | 選択色が変わらない |
| 13 | GUI: カスタム タブを列数 0 と 1 以上で表示する | 0 は色名付きの一覧、1 以上は色の四角だけの格子になる（名前はツールチップ） |
| 14 | GUI: 項目へポインターを載せる | ツールチップが 2 行（色名 + 不透明度 / カラーコード）で出る |
| 15 | GUI: 同じ色を選び直す | `ColorApplied` は出るが `SelectedColorChanged` は出ない |
| 16 | GUI: ホストがピッカーのテーマを取り込んでいない状態で開く | 既定の見た目で表示され、例外は出ない |

## 2. 人が実施する項目（AI は実施できない）

画面キャプチャでは判定できない項目です。 人が操作して確かめ、**AI が実施できない理由**を表の最後の列に示します。

### 2.1 一覧の表示

| # | 操作（API / GUI） | 期待結果 | AI が実施できない理由 |

| 5 | GUI: 表示倍率 150%・200% にする | 入力欄の文字と色の四角が滲まず、大きさが崩れない | 表示倍率の切り替えは OS の設定であり、確かめるたびにサインアウトと再ログオンが要る |
