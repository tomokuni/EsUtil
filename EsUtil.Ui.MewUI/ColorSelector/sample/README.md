## 1. 概要

`EsUtil.Ui.MewUI/ColorSelector/sample/` にある **ColorSelectorControl 動作確認用の独立したサンプルアプリケーション**です。

- 設定画面と同じ形（ラベルとコントロールを並べる）で 4 つの色を編集できます（枠線・背景・テキスト・強調）。
- 選択した色の**保存値（`#AARRGGBB`）**が画面の下に表示されます。
- 2 つの色（枠線と背景）はプレビューの枠と背景へ即時反映されます。
- 入力欄は標準のコンボボックスで、左に**現在色の四角**を出して「■ + 色名」の形で表示します（文字は四角の右から始まり、上下の中央にそろいます）。 展開すると **カスタム / テーマカラー / 色名 / ColorPicker** のタブ付き一覧が開きます（テーマの色は数が多いため分けています）。 一覧の並び順（色相順 / 色名順）と入力欄の表記（色名 + 不透明度 / `#AARRGGBB`）も切り替えられます。
- 設定のチェック項目で、タブの表示（カスタム / テーマカラー / 色名 / ColorPicker / 題名）と「代表色」タブ（**色の四角を 6 列に並べた格子**）を切り替えられます。

## 2. 実行方法

```powershell
dotnet run --project EsUtil.Ui.MewUI/ColorSelector/sample/EsUtil.Ui.MewUI.ColorSelector.Sample.csproj
```

## 3. 操作方法

| 操作 | 内容 |
| --- | --- |
| 「表示テーマ」を切り替える | サンプル共通の設定行（`SampleTheme`）。 コントロールはフレームワークのテーマから明暗を読むため、指定は不要 |
| テキスト欄へ入力 | 色名（`Red`）/ 16 進（`#RRGGBB`・`#AARRGGBB`）/ 不透明度（`Red+50%`）を受け付ける。 左の四角は入力中の色を映し、無効な入力の間は隠れる |
| 展開ボタン（コンボボックスの▼） | タブ付きの一覧を開く（標準の一覧は開かず、開閉が往復しない。 タブを選び、クリックで選択して保存値へ反映） |
| Alt+↓ / F4 | キーボードでも同じタブ付きの一覧を開く |
| ColorPicker タブ | 一覧を閉じてカラーピッカーを開く（MewUI の `ColorPicker` はドロップダウン。 選ぶと即時に反映） |
| 一覧の並び順 | 「色相順」「色名順」を切り替える（すべての行へ反映。 タブ「色名」の並びが変わる） |
| 入力欄の表記 | 「色名 + 不透明度」「#AARRGGBB」を切り替える（すべての行へ反映） |
| タブのチェック項目 | 「カスタム」「テーマカラー」「色名」「ColorPicker」「タブの題名」の表示を切り替える |
| 「代表色」タブを追加（格子） | よく使う 16 色を **6 列の格子**で並べたタブを足す（名前はツールチップ） |
| 入力欄へ重ねる | ツールチップに「色名 + 不透明度」と「#AARRGGBB」が 2 行で出る |
| フォーカスを外す | 無効な入力を最後の有効値へ戻す |

## 4. 検証項目（動作確認チェックリスト）

- [ ] 起動時に 4 行の色が表示され、保存値が画面の下に出る
- [ ] 入力欄の左に現在色の四角が出て、文字が四角に重ならず上下の中央でそろう（無効な入力の間は四角が消える）
- [ ] `Red` と入力すると保存値が `#FFFF0000` になる
- [ ] `Red+50%` と入力すると保存値が `#80FF0000` になる
- [ ] `NotAColor` と入力するとエラー表示が出て、フォーカスを外すと元の値へ戻る
- [ ] 展開ボタンで一覧が開き、色を選ぶと保存値とプレビューが変わる
- [ ] 一覧のタブで「カスタム」「テーマカラー」「色名」を切り替えられる
- [ ] 「代表色」タブを追加すると、16 色が 6 列の格子で並ぶ（スクロールしない）
- [ ] 「ColorPicker」タブを選ぶと一覧が閉じ、カラーピッカーが開く
- [ ] 「色名順」へ切り替えると、すべての行の一覧がアルファベット順になる
- [ ] 「#AARRGGBB」へ切り替えると、すべての行の入力欄が `#AARRGGBB` の表記になる
- [ ] 1 番目の色を変えるとプレビューの枠、2 番目を変えるとプレビューの背景が変わる
- [ ] 無効な色を入力してフォーカスを外すと最終有効値へ復帰し、枠線が赤くなる（「入力が無効なら枠線を赤くする」が ON のとき）
- [ ] 「文字サイズ」「入力欄の幅」「入力欄の最小幅」「入力欄の最大幅」の変更が入力欄の見た目に反映される

## 6. 使い方（初めての方向け）

1. **起動**: 4 行の色選択とプレビューが表示されます。
2. **入力**: テキスト欄へ色名や 16 進を入力すると、その場で保存値が更新されます。
3. **一覧**: 展開ボタン（コンボボックスの▼）を押すとタブ付きの一覧が開きます。 上部のタブで「カスタム / テーマカラー / 色名 / ColorPicker」を切り替えます。 並び順は画面の「一覧の並び順」で、入力欄の表記は「入力欄の表記」で切り替えます。
4. **ピッカー**: 「ColorPicker」タブを選ぶと、一覧が閉じてカラーピッカーが開きます（アルファも編集できます）。
5. **保存値**: 設定へ保存する値は `SelectedColor`（`#AARRGGBB`）です。 色名で入力しても正規化されます。
